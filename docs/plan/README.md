# docs/plan/

기획서에서 파생된 **개발 스펙**을 두는 폴더입니다.
기획서가 "무엇을, 왜"를 정한다면, 이 폴더는 "어떻게 구현할지"를 구체화합니다.

## 원칙

- 기획 원본과 모순되면 **원본이 우선**합니다. 이 폴더의 문서를 고칩니다.
- 원본에 없는 결정(버전, 포트, 세부 API 필드 등)은 여기서 확정하고, 확정 전에는 `미정`으로 둡니다.
- 문서마다 기준이 된 기획서 절을 적습니다. 예: `기준: 기획서 v1.2 §11`
