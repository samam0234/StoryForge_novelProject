## 결정 대기

- **기획서 반영 여부:** 커뮤니티는 기획서 Phase 1~3에 없던 범위입니다 (협업은 Phase 3 "검토"). 기획서 본문은 고치지 않았습니다. 정식으로 넣으려면 승인 후 버전을 올립니다.
- **Clone 원고의 Continuity:** 전체 원고 Clone은 이 프로젝트 기준의 검증 결과 없이 시작합니다. 지금은 승인할 때 확인을 받습니다. "편집한 챕터 재검증"을 결정할 때 함께 정합니다.
- **Codicomperchat:** 주소와 연동 규격을 받아야 합니다. 지금은 설정한 주소로 새 창을 여는 것까지만 있습니다.

## 알려진 제한

- **편집한 챕터의 요약·Continuity는 다시 만들지 않습니다.** 다음 챕터 컨텍스트에는 AI가 생성할 때 만든 요약이 들어가므로, 검토 중 내용을 크게 고치면 요약과 어긋날 수 있습니다. 해결하려면 승인할 때 AI 재요약·재검증이 필요해 비용·시간이 늘어납니다. 사용자 결정 대기입니다.
- 캐릭터 `currentState` 자동 갱신은 Phase 2 항목이라 아직 없습니다.
- 실제 Claude API 호출은 검증하지 못했습니다 (보류).
