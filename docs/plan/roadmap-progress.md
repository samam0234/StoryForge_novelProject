## 결정 대기

- **기획서 반영 여부:** 커뮤니티와 관리 기능은 기획서 Phase 1~3에 없던 범위입니다 (협업은 Phase 3 "검토"). 기획서 본문은 고치지 않았습니다. 정식으로 넣으려면 승인 후 버전을 올립니다.
- **Codicomperchat:** 주소와 연동 규격을 받아야 합니다. 지금은 설정한 주소로 새 창을 여는 것까지만 있습니다.
- **메일 발송 수단:** SMTP 방식 구현·로컬 검증 완료. 실제 공급자와 발신 주소, 외부 수신 검증은 남아 있습니다.
- **이용약관:** 법률 검토 전 초안입니다.
- **브라우저 검증과 외부 배포:** 콘솔·메일 화면·사용자 웹 주요 흐름과 외부 문서 리더 확인은 남아 있습니다. 사용자가 이후 코드 진단·문서 수정 후 병합·푸시를 직접 명령해 이전 보류를 변경했습니다. 배포는 제외합니다. [최신 결과](../vaildates/diagnostics-integration.md).
