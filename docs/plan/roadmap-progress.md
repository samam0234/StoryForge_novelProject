## 결정 대기

- **기획서 반영 여부:** 커뮤니티와 관리 기능은 기획서 Phase 1~3에 없던 범위입니다 (협업은 Phase 3 "검토"). 기획서 본문은 고치지 않았습니다. 정식으로 넣으려면 승인 후 버전을 올립니다.
- **Codicomperchat:** 주소와 연동 규격을 받아야 합니다. 지금은 설정한 주소로 새 창을 여는 것까지만 있습니다.
- **메일 발송 수단:** 이메일 인증과 비밀번호 재설정에 필요합니다. 공급자와 발신 주소를 정해야 합니다.
- **이용약관:** 법률 검토 전 초안입니다.
- **브라우저 검증과 외부 배포:** 이번 콘솔은 브라우저 미검증을 기록하고 로컬 병합하도록 사용자 지시를 받았습니다. 배포 환경 검증과 원격 반영은 별도입니다.

## 알려진 제한

- 캐릭터 `currentState` 자동 갱신은 Phase 2 항목이라 아직 없습니다.
- 실제 Claude API 호출은 검증하지 못했습니다 (보류).
