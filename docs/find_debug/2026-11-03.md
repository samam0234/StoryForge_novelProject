# 2026-11-03

커뮤니티 기능을 브라우저로 확인하다 찾은 문제입니다.

## 1. 원고의 HTML 태그가 내보내기에서 사라짐

- **증상**: 본문의 `<script>` 같은 태그가 HTML 내보내기 결과에서 통째로 없어짐. 안전하지만 글자가 사라짐.
- **원인**: commonmark가 태그를 `HtmlInline`·`HtmlBlock`으로 분리하는데 `ManuscriptBlocks`가 이 노드를 무시함. DOCX·PDF도 같았음.
- **해결**: 태그를 글자로 남기고 각 작성기가 이스케이프.
- **재발방지**: 내보내기 통합 테스트에 태그가 든 원고를 넣음.

## 2. 활동 잔디를 누르면 프로필 탭이 처음으로 돌아감

- **증상**: 활동 내역 탭에서 잔디 칸을 누르면 작품 탭으로 돌아감.
- **원인**: 프로필을 읽는 `effect`가 `loadFeed` 안의 날짜·페이지 신호까지 추적해, 날짜를 바꾸면 프로필 전체를 다시 읽고 탭을 다시 그림.
- **해결**: `untracked`로 감쌈.
- **재발방지**: `features/README.md` 규칙에 추가. `effect`에서는 일부러 추적할 신호만 읽습니다.

## 3. 화면이 가로로 밀림

- **증상**: 요소로 스크롤하면 왼쪽 메뉴가 사라지고 화면이 왼쪽으로 밀림.
- **원인**: 닫힌 오른쪽 `mat-sidenav`가 `transform`으로 화면 밖에 있어도 스크롤 영역을 늘림.
- **해결**: 가이드챗을 사이드 내비에서 일반 패널로 변경. 열 때만 존재합니다.

## 4. 패키지 지도의 작품 제목이 잘림

- **증상**: 좌우 끝의 작품 제목이 SVG 밖으로 나감.
- **해결**: 좌표 공간을 560에서 680으로 넓힘.
