# 2026-11-11 생성 품질과 메일 전달

## 메일

루트 `.env`에 SMTP 항목이 없었습니다. Gmail STARTTLS 설정을 로컬 파일에 추가했고 비밀번호는 사용자가 입력합니다. Spring Boot는 일반 실행에서 `.env`를 자동으로 읽지 않으므로 `storyforge-backend/scripts/start-local.ps1`이 파일을 데이터로 읽어 프로세스 환경에 주입합니다. 셸 표현식은 실행하지 않습니다.

인증 메일 SMTP 실패를 성공 응답으로 돌려주던 경로는 503으로 변경했습니다. 공개 비밀번호 재설정 요청은 계정 존재 여부를 노출하지 않는 동일 응답을 사용합니다. SSL 전용 SMTP도 `SMTP_SSL`로 설정할 수 있습니다.

## 창작 컨텍스트와 생성

최초 창작 프롬프트가 Bible 생성 후 직접 전달되지 않았습니다. V14의 `project.creative_brief`에 성공한 생성 요청을 저장하고 이후 AI 요청에 보냅니다. 작품 형식·장르·제목·기본 톤, 전체 Outline과 직전 확정 장 마지막 1,200자를 챕터 컨텍스트에 포함합니다. 기존 작품은 창작 요구가 비어 있어도 동작합니다.

실모델의 요약과 연속성 검사를 구조화 호출 하나로 합쳐 본문 후 모델 호출을 두 번에서 한 번으로 줄였습니다. 규칙 검사와 모델의 모든 이슈를 합산합니다. 긴 문장 세 번 반복과 구분 없는 반복 루프를 감지하면 스트림을 오류로 종료하고 연결을 해제합니다.

초기 변경 후 Gemma 한 회차에서 첫 토큰 0.110초, 생성·분석 26.197초, 본문 3,474자, 포화 거부·중단 후 재사용 각 1회를 확인했습니다. 목표 분량 미달이며 이전 시험과 조건이 달라 속도 개선율을 산정하지 않습니다.

## 커뮤니티 운영

동시 중복 신고는 조회 후 삽입 사이에 유일 인덱스 충돌이 가능했습니다. 신고 접수에 기존 운영 잠금을 적용해 중복 접수와 관리자 조치를 직렬화합니다. 동시 두 요청이 같은 접수 번호를 받는 회귀 검사를 추가했습니다.

## 검증 범위

AI 67건 및 Pyright 오류·경고 0건을 확인했습니다. 로컬 Docker 엔진이 실행되지 않아 첫 Java 검사는 통합 테스트를 건너뛰었습니다. 건너뛴 검사를 통과로 계산하지 않으며 원격 CI에서 PostgreSQL·SMTP 통합 검사를 확인합니다. Gmail 실제 발송은 앱 비밀번호 입력 후 확인해야 합니다.
