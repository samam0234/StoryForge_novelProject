# docs/find_debug/

날짜별 **디버그 일지**를 두는 폴더입니다. 문제를 조사하고 해결한 기록을 남겨, 같은 문제를 다시 파지 않게 합니다.

## 파일명

`YYYY-MM-DD.md` — 하루에 파일 하나. 같은 날 여러 건이면 한 파일 안에 항목을 나눕니다.

## 템플릿

```markdown
# YYYY-MM-DD

## 1. 이슈 제목

- **증상**: 무엇이 어떻게 잘못 보였는지 (에러 메시지, 재현 절차)
- **원인**: 확인된 원인 (추정이면 추정이라고 표시)
- **해결**: 한 일과 관련 커밋
- **재발방지**: 테스트 추가, 문서 갱신, 설정 변경 등
```
