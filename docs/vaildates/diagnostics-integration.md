# 코드 진단과 통합 검증 — 2026-11-10

## 범위와 사용자 지시

사용자가 노란색·빨간색 코드 진단 수정, 문서 갱신, 커밋 → 병합 → 푸시를 직접 요청했습니다. 이번 명령에 따라 `feature/auth → develop → main`을 `--no-ff`로 통합하고 원격에 반영합니다. 이전 브라우저 검증 전 병합 보류는 이번 직접 명령으로 변경됐습니다. 배포는 수행하지 않습니다.

브라우저와 VS Code UI의 직접 관찰은 도구 접근 제한으로 미완료입니다. 컴파일·타입 검사 결과를 실제 화면 검증이나 편집기 문제 패널의 관찰로 바꾸어 기록하지 않습니다.

## 재현과 수정

- Python: 초기 17건과 복구 스크립트 추가 11건. 종료 가능한 스트림을 `AsyncGenerator`로 선언하고, 테스트 대역·선택 의존성 로딩·비동기 결과 반환·JSON 결과 소비를 정리했습니다. Pyright 진단을 끄지 않았습니다.
- Java: 예외 직렬화 버전 누락 5건, 운영 코드 추가 null 분석 경고 6건. 명시적 직렬화 버전·COUNT 필수 결과·주소 파싱 반복문으로 수정했습니다.
- 검증 도구: 짧은 반복 시험이 예열만 수행하고 0회 성공으로 끝나는 문제를 실패 테스트로 재현했습니다. 최소 한 회차를 실행하도록 수정하고 회귀 테스트를 추가했습니다.
- 개발 환경: 루트 Pyright 설정과 venv 경로·TypeScript SDK 제안 설정, 생성물 Git 제외를 정리했습니다. AI CI는 동일 venv에서 타입 검사와 테스트를 수행합니다.

## 한계와 후속 확인

- 편집기 UI 접근은 자동 승인 검토가 거부했으며 상세 사유가 제공되지 않았습니다. 특정 문제 패널 표시를 직접 확인한 결과가 아닙니다.
- 선택적인 null 분석을 테스트까지 확장하면 AssertJ 제네릭 SELF 등 라이브러리 계약에 경고가 남습니다. 기본 검사·운영 코드 검사와 구분하며 진단 설정을 비활성화하지 않았습니다.
- Maven 의존성이 선언한 비공개 Flyway 저장소의 메타데이터 요청 401과 JDK의 Mockito 동적 에이전트 안내는 코드 진단과 별도입니다. 빌드·테스트는 통과했으며 이를 감추기 위해 자격 증명이나 보안 설정을 바꾸지 않았습니다.
- 브라우저·외부 문서 리더·다양한 실제 작품·다중 사용자 부하는 후속 확인 대상입니다. [브라우저 연결 진단](../repeater/browser-automation-host.md).
- 원격 CI 결과는 GitHub Actions의 해당 푸시 실행에서 확인합니다. 로컬 결과를 원격 CI 통과로 간주하지 않습니다.

## 최초 푸시 뒤 확인한 CI 차이

첫 main 통합 `f22bec8`의 [CI 실행](https://github.com/samam0234/StoryForge_novelProject/actions/runs/42812935162)은 프론트·콘솔 작업이 성공했지만 백엔드가 Maven Wrapper 실행 권한 부족으로 테스트 전에 종료 코드 126을 반환했습니다. Git에 저장된 `mvnw` 실행 비트를 바로잡아 후속 작업 브랜치 커밋·develop→main 병합·푸시로 반영합니다. Wrapper 원문과 기존 테스트 조건은 바꾸지 않습니다. 해당 첫 실행은 성공으로 기록하지 않습니다.
