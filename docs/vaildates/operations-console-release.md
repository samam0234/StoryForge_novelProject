## 추가 디버깅과 문서 대조

동일 작성자의 복수 대상 정지·해제와 공백 AI 스트림을 회귀 테스트로 먼저 실패시킨 후 수정했습니다. 위 표는 수정 후 다시 실행한 **총 198건**과 두 Angular 프로덕션 빌드의 결과입니다. 실제 Ollama 속도 수치는 앞선 측정이며 이번에 다시 측정한 수치로 표시하지 않습니다.

원인·재현·해결·재발 방지는 [2026-11-10 디버깅 일지](../find_debug/2026-11-10.md)에 남겼습니다. 현재 문서의 내부 링크, 실행 환경 변수 주입, 운영 API 의미, 테스트 수를 대조합니다. 기획 원본·규칙·과거 커밋 기록은 현재 구현에 맞춰 덮어쓰지 않습니다.

문서 링크 점검 결과: 기획 원본·규칙·과거 커밋 기록을 제외한 Markdown **62개**, 로컬 링크 **332개**, 없는 경로 **0개**. 실행 데이터 제외 경로 두 개는 `git check-ignore --no-index`에 매칭되고 이름 풀은 계속 추적되는 것을 확인했습니다.

## 브라우저 검증 제한

브라우저 연결 호스트를 사용할 수 없었고, Windows Chrome 자동화도 현재 URL을 신뢰성 있게 확인할 수 없어 도구의 안전 검사에서 중단됐습니다. **브라우저 렌더링·클릭·반응형 화면 검증은 수행하지 못했습니다.** 사용자가 2026-11-10 이 제한을 기록하고 병합까지 진행하도록 직접 지시했습니다. Angular 테스트·빌드·실제 HTTP 프록시 검증을 브라우저 검증으로 간주하지 않습니다.

## 배포 전 남은 수동 확인

- [ ] 운영자 로그인과 일반 회원 접근 거부를 실제 브라우저에서 확인
- [ ] 현황·신고·회원·감사 화면의 데스크톱·모바일 표시와 키보드 이동 확인
- [ ] 신고 선택·사유 입력·조치 후 결과, 회원 정지·해제·감사 이력 확인
- [ ] 만료·401·403·409·연결 실패 화면 확인
- [ ] 실제 배포 도메인의 TLS, CORS, SPA fallback, `/api` 프록시 확인
- [ ] 배포 서버에서 긴 창작 컨텍스트와 동시 요청의 지연·VRAM 확인
- [ ] 관리자 계정 선확보, `ADMIN_EMAILS`, `JWT_SECRET`, DB 자격 증명 설정

외부 배포는 이번 작업에서 실행하지 않습니다. 과거 감사 이력의 소급 생성과 실제 Claude API 검증도 포함하지 않습니다.
