자동 테스트가 다루는 범위는 [storyforge-backend/src/test/README.md](../../storyforge-backend/src/test/README.md)에 있습니다. 여기는 **사람이 눈으로 봐야 하거나 환경에 달린 것**만 적습니다.

## 사전 조건

- [ ] `./mvnw test` 건너뜀 없이 통과, `pytest` 통과, `npx ng test --watch=false` 통과
- [ ] **`npx ng build` 통과** (단위 테스트는 화면 템플릿을 모두 컴파일하지 않습니다)
- [ ] [SECURITY.md](../../SECURITY.md)의 배포 전 체크리스트 완료

## 법적·운영

- [ ] 이용약관을 법률 검토했고 초안 표시를 뺐다
- [ ] 약관 문구를 바꿨다면 시행일과 `TERMS_VERSION`을 올렸다
- [ ] `ADMIN_EMAILS`를 지정했고 그 주소의 계정을 먼저 만들었다
- [ ] 신고를 누가 얼마나 자주 처리할지 정했다

## 보여야 할 것과 보이면 안 되는 것 (로그아웃 상태)

- [ ] 게시판, 작품 읽기, 프로필, 이슈가 열린다
- [ ] 비공개 작품과 숨긴 작품은 404다
- [ ] 프로필과 작품 응답에 이메일이 없다 (개발자 도구로 확인)
- [ ] 작업 그래프에 본문이 없다
- [ ] 공유 링크를 새 브라우저에서 열 수 있다

## 파이프라인 원칙

- [ ] 검토 중 챕터는 게시본에 들어가지 않는다
- [ ] 전체 원고 Clone이 자동 승인되지 않는다
- [ ] 고친 챕터를 승인하면 다음 챕터 컨텍스트에 수정본 요약이 들어간다

## 내보내기 (자동 테스트는 파일 구조까지만 확인)

- [ ] EPUB을 전자책 뷰어에서 연다
- [ ] ODT를 LibreOffice에서 연다
- [ ] RTF, DOCX를 Word에서 연다 (한글, 굵게, 인용)
- [ ] PDF의 한글이 깨지지 않는다

## 실제 LLM (mock으로는 확인할 수 없음)

- [ ] 수정본 재요약의 품질
- [ ] 패키지 전체 검사가 작품 사이의 모순을 찾아내는지
- [ ] 가이드챗 자유 질문이 없는 기능을 지어내지 않는지
- [ ] 다른 작가가 설정을 공개하지 않은 작품이 프롬프트에 없는지 (로그로 확인)
