## 주 내용

저장소에 커밋이 없어 develop과 작업 브랜치를 만들 수 없었으므로, main에 빈 초기 커밋을 만들었습니다.

## 상세

- 파일 변경 없음 (`--allow-empty`)
- 기존 기본 브랜치 이름 `master`를 `main`으로 맞췄습니다 (git 상태의 메인 브랜치 기준)
- 이 커밋 이후 `develop`을 `main`에서, `feature/project-scaffold`를 `develop`에서 분기했습니다

## 결과

- `main`에 직접 커밋하지 않도록, 이 기록 파일은 `feature/project-scaffold`에 커밋합니다
- 이후 일반 작업은 `feature/*`에서만 합니다
