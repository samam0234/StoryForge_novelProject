# 커밋 기록 템플릿

> 이 파일을 복사해 `commits/YYMMDD_HHMM_[커밋ID]_[커밋이름]_[브랜치].md`로 저장합니다.
> 섹션 4개(제목/커밋번호, 주 내용, 상세, 결과)는 생략하지 않습니다. 이 인용 블록은 지웁니다.

---

## 제목 / 커밋번호

- **제목**: `type(scope): 한국어 요약`
- **커밋번호**: `a1b2c3d`
- **브랜치**: `feature/xxx`
- **일시**: YYYY-MM-DD HH:MM

## 주 내용

이 커밋이 무엇을, 왜 바꾸는지 한두 문장으로 적습니다.

## 상세

- 변경한 파일과 변경 내용
- 기획서·정본에서 근거가 된 절 (예: 기획서 §7.2)
- 함께 갱신한 문서 (`Architecture/`, `CURRENT_STACK.md` 등)

## 결과

- 확인한 방법 (실행, 테스트, 수동 확인)과 결과
- 남은 작업이나 후속 커밋
