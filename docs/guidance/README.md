# docs/guidance/

실행 방법과 기능 사용법을 적는 가이드 폴더입니다. 처음 보는 사람도 그대로 따라 하면 되도록 씁니다.

## 작성 순서

모든 가이드는 **전제 → 명령 → 기대결과** 순서로 씁니다. 포트와 환경 변수는 표로 정리합니다.

## 파일명

`주제.md` (kebab-case). 예: `local-dev-setup.md`, `run-storyforge-ai.md`

## 템플릿

````markdown
# 가이드 제목

## 전제
- 필요한 도구와 버전 (값은 ../plan/CURRENT_STACK.md 기준)
- 먼저 끝나 있어야 하는 단계

## 포트 / 환경 변수
| 이름 | 값 | 설명 |
|------|----|------|

## 명령
```
실행할 명령
```

## 기대결과
- 성공했을 때 보이는 출력이나 화면
- 실패하면 확인할 곳 (../find_debug/, ../repeater/)
````
