# docs/novel/

창작 파이프라인 관련 문서를 두는 폴더입니다. 세계관 템플릿, 프롬프트 가이드, Continuity 규칙을 여기에 정리합니다.

## 다루는 내용 (기획서 §6 기준)

| 주제 | 내용 | 기준 절 |
|------|------|---------|
| Story Bible 템플릿 | 세계관, 캐릭터 프로필(이름, 성격, 외모, 관계, 목표, 현재 상태), 설정, 테마, 톤 | §6.1, §10 |
| Outline 템플릿 | 챕터별 제목, 주요 Beats, 등장 캐릭터, 긴장/감정 목표, 연속성 포인트 | §6.2, §10 |
| 프롬프트 가이드 | 컨텍스트 조립 순서, 주입 규칙, 작성 원칙 | §6.3, §7.2 |
| Continuity 규칙 | 설정 충돌, 캐릭터 일관성, 타임라인, 플롯 스레드 검증 기준 | §6.3 |

## 원칙

- Story Bible, Outline, Continuity 관련 문서에도 정본 §0(원본 보존)을 적용합니다. 요청받은 범위만 고칩니다.
- 설정 붕괴(할루시네이션, 캐릭터 OOC, 타임라인 오류)를 부르는 규칙 변경은 하지 않습니다.
- 챕터 생성 컨텍스트에는 Story Bible + Outline + 이전 챕터 요약을 반드시 넣습니다.
- 이 폴더는 **규칙과 가이드**입니다. 실제 프롬프트 템플릿 파일은 [storyforge-ai/app/prompts/](../../storyforge-ai/app/prompts/)에 둡니다.
- 생성된 소설 원문과 실유저 데이터는 넣지 않습니다.
