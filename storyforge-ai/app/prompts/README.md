# storyforge-ai/app/prompts/

**프롬프트 템플릿** 파일(`.txt` 또는 Jinja)을 둡니다.

## 들어갈 것

- 단계별 템플릿 (Bible, Outline, Chapter, Continuity)
- 컨텍스트 주입 자리표시자

## 들어가지 않을 것

- 코드 안에 하드코딩한 긴 프롬프트
- 실유저 데이터, 생성 소설 원문 예시
