# storyforge-frontend/src/app/features/outline/

**Outline 관리** 화면입니다. 챕터별 구성을 보고, 순서를 바꾸고, Beats를 편집합니다.

## 들어갈 것

- 챕터 카드 또는 타임라인 뷰, 드래그 앤 드롭 재배치 (§9.6 3번)
- 챕터별 제목, 주요 Beats, 등장 캐릭터, 긴장/감정 목표, 연속성 포인트 편집 (§6.2)
- 생성 요청 `POST /api/v1/projects/{id}/outline/generate` (§11)

## 들어가지 않을 것

- Outline 생성 프롬프트, LLM 호출
