# storyforge-frontend/src/app/shared/components/

여러 화면에서 재사용하는 **기능성 컴포넌트**입니다.

- 파이프라인 단계 표시 ("단계적 진행 가시화", §9.1)

## 들어가지 않을 것

- 디자인 토큰 수준의 기본 UI → `shared/ui/`
