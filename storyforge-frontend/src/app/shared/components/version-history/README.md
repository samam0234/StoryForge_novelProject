# storyforge-frontend/src/app/shared/components/version-history/

버전 이력을 비교하는 다이얼로그입니다 (기획서 §6.1, §6.4). Story Bible과 챕터가 함께 씁니다.

## 현재 파일

| 파일 | 내용 |
|------|------|
| `version-history.dialog.ts` | 두 버전을 골라 단어 단위 Diff 표시. 선택한 버전을 편집기로 불러오기 |

## 들어갈 것

- 이력 표시와 비교

## 들어가지 않을 것

- 이력 조회 API 호출, 저장 → 사용하는 화면. 불러오기는 편집기에 채우기만 하고 저장은 사용자가 합니다
