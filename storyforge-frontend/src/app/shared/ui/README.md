# storyforge-frontend/src/app/shared/ui/

Angular Material을 감싼 **디자인 시스템 컴포넌트**입니다. 색상과 타이포는 디자인 토큰을 따릅니다.

## 들어갈 것

- 버튼, 카드, 패널, 탭 등 기본 UI
- Material 커스텀 테마를 적용한 래퍼

## 들어가지 않을 것

- 화면 로직, API 호출
