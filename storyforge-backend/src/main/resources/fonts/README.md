# storyforge-backend/src/main/resources/fonts/

PDF 내보내기에 내장하는 한글 글꼴입니다. 내장하지 않으면 PDF에서 한글이 깨집니다.

## 현재 파일

| 파일 | 내용 |
|------|------|
| `NanumGothic-Regular.ttf`, `NanumGothic-Bold.ttf` | 나눔고딕 (SIL Open Font License) |
| `OFL.txt` | 글꼴 라이선스 전문. 글꼴과 함께 배포해야 합니다 |

## 들어가지 않을 것

- 화면용 글꼴 (프론트는 Pretendard CDN)
